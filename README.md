# HSH Gold Board

หน้าเว็บมือถือหน้าเดียว กดปุ่มแล้วดึงราคาทองฮั่วเซ่งเฮง (ทองแท่ง 96.5%, ทอง 99.99%, สถานะตลาด) พร้อมเวลาอัปเดตและคำเตือนเมื่อข้อมูลค้าง

- `index.html` เว็บรุ่นแรก ไม่มีคีย์ ไม่มีรหัสผ่าน ไม่มีฟังก์ชันซื้อขาย
- `test.html` หน้าทดสอบว่าเรียก endpoint ของ HSH จากโดเมนนี้ได้หรือไม่

ข้อควรรู้

- ข้อมูลมาจาก endpoint ที่หน้าเว็บ huasengheng.com ใช้อยู่ ไม่ใช่ API ทางการ อาจเปลี่ยนหรือปิดได้โดยไม่แจ้ง
- ดึงเฉพาะตอนกดปุ่ม และไม่ดึงซ้ำภายใน 5 นาที
- ข้อมูลประกอบการตัดสินใจ ไม่ใช่คำแนะนำการลงทุน
